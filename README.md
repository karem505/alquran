# مصحفي — قارئ القرآن الكريم على لينكس

تطبيق سطح مكتب أصلي لقراءة القرآن الكريم بنفس رسم وشكل المصحف (رواية حفص عن عاصم، الرسم العثماني، طبعة مصحف المدينة النبوية الجديدة ١٤٤١هـ).

## المزايا

- عرض صفحتين متجاورتين بكامل الشاشة كما في المصحف المطبوع (يمين: فردي، يسار: زوجي) مع أرقام الصفحات
- هوية بصرية دافئة: بيج/كريمي + ذهبي
- شريط علوي حي: السورة/الجزء/الحزب/الربع/الصفحة الحالية أثناء التنقل
- قائمة تقسيمات (سورة/جزء/حزب/ربع) تفتح على موضع القراءة الحالي
- بحث: كلمة / اسم سورة / حرف — مع الانتقال للصفحة
- يعمل دون إنترنت

## التقنية

- Quickshell 0.3.1 (Qt 6 / QML) — نافذة تطبيق أصلية (FloatingWindow) على Wayland/Hyprland

## المصادر

- صور الصفحات: مصحف المدينة النبوية برواية حفص — طبعة ١٤٤١هـ، مجمع الملك فهد لطباعة المصحف الشريف (نسخة PDF عبر أرشيف الإنترنت)
- النص العثماني والقوائم (جزء/حزب/ربع/صفحة): بيانات قرآنية مفتوحة

## الهيكل

```
shell.qml      — نقطة الدخول (Quickshell)
app/           — مكونات QML
tools/         — سكربتات بناء الفهرس (Python)
data/          — فهارس JSON مولّدة
pages/         — صور الصفحات 604
```

## التشغيل

```bash
qs -p shell.qml
```
